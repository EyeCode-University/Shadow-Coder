## Суть задания

Создай **кликер-игру** по типу Bloom (Telegram игра). Пользователь кликает на объект, зарабатывает монеты, может покупать улучшения для автоматического заработка и увеличения дохода за клик.

## 📋 Основная механика

### 1️⃣ Система кликов

**При клике на объект:**
- Анимация (scale, pulse)
- +1 монета к балансу
- Визуальный эффект (+1 всплывающая цифра)
- Звук клика (опционально)

**Энергия:**
```
┌──────────────────────┐
│ ⚡ Энергия: 85/100   │
└──────────────────────┘
```
- Каждый клик = -1 энергия
- Восстановление: +1 энергия каждые 3 секунды
- Без энергии кликать нельзя

---

### 2️⃣ Улучшения

| Улучшение | Эффект | Начальная цена |
|-----------|--------|----------------|
| **Авто-клик** | +1 монета/сек | 50 монет |
| **Множитель клика** | Клик даёт x2 монет | 100 монет |
| **Максимум энергии** | +10 к лимиту энергии | 75 монет |
| **Скорость восстановления** | Энергия быстрее x1.5 | 150 монет |

**Механика цен:**
```javascript
// Цена растёт с каждой покупкой
newPrice = basePrice * Math.pow(1.15, level)
```

### 4️⃣ Логика автоматического дохода

```javascript

setInterval(() => {
  const income = autoClickLevel * 1; // уровень * доход
  balance += income;
  updateBalance();
}, 1000);
```
